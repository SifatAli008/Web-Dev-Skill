Universal WebDev Skills

An open-source, tool-agnostic framework that equips AI coding agents with the engineering rigor, architectural discipline, and security posture of an elite 15-specialist team.

Most AI coding assistants act as eager junior developers: they generate syntax quickly, but frequently skip input sanitization, concatenate raw SQL strings, leak secrets in git commits, claim tests pass without running them, or over-engineer 2-user hackathon prototypes with distributed microservices.

💡
The Universal Solution
Universal WebDev Skills fixes this by enforcing deterministic 3-tier classification (MVP, PROD, SCALE), non-negotiable security vetos, and schema-validated handoffs across Cursor, Claude Code, Antigravity, GitHub Copilot, and Gemini.
Documentation / Getting Started

5-Second Quickstart

Install the framework into any repository in seconds using the zero-dependency CLI installer.

Run the interactive installer directly in your project root:

Terminal 
npx webdev-skills init

Or install your preferred AI agent adapter directly with specific flags:

Terminal Direct Flags 
npx webdev-skills init --tool cursor       # Installs .cursorrules and .cursor/rules/*.mdc
npx webdev-skills init --tool claude       # Installs CLAUDE.md
npx webdev-skills init --tool antigravity  # Installs GEMINI.md
npx webdev-skills init --tool copilot      # Installs .github/copilot-instructions.md
npx webdev-skills init --tool gemini       # Installs GEMINI.md
npx webdev-skills init --tool chatgpt      # Installs system-prompt.md

The 3-Tier Rigor Standard

Every task is classified into MVP, PROD, or SCALE based on concrete, objective signals. The agent must always adopt the highest tier triggered.

Tier Activation Signals Engineering Standard Quality Gate
MVP Internal tools, proofs of concept, hackathon apps. Zero public customer data. Speed prioritized. Single-file simplicity, parameterized SQLite, scrypt hashing, basic defensive CSP. Unit test primary happy path; zero critical findings.
PROD Public users, user accounts, email capture, checkout/payments, revenue at stake. ACID transactions, Idempotency-Keys, /liveness & /readiness probes, zero-downtime expand/contract migrations, strict HSTS. 100% route test coverage, OWASP Top 10 scanner, automated rollback scripts.
SCALE >100k MAU, spiky traffic patterns, high-volume payouts, strict high-availability SLAs. Edge caching (s-maxage, stale-while-revalidate), ETag conditional GET (304), absolute zero CLS (CLS = 0), cookieless analytics. Chaos resilience tests, mutation testing, performance budget CI checks.
⚠️
Non-Negotiable Rule
Never build or ship a PROD or SCALE signal at MVP rigor unless the user explicitly acknowledges and accepts the risk in DECISIONS.md.

Binding Gates & Hard Vetos

Specialists possess real, non-overridable veto power. The AI agent cannot bypass an architectural or security invariant.

Specialist Role Authority Veto Trigger & Non-Negotiable Criterion
06 Application Security HARD VETO Raw SQL string concatenation, leaked credentials in git history, unauthenticated payment routes, un-salted password hashes.
07 Privacy Officer HARD VETO Pre-consent third-party tracking cookies, unencrypted personal data storage, missing GDPR/CCPA deletion mechanisms.
08 SQAT & Testing Lead No Evidence, No Ship Rejecting completion claims without terminal command output, exit codes, and automated test assertions.
09 DevOps / SRE Lead No Rollback, No Ship Deploying code lacking independent container health probes or tested rollback scripts.
02 Solution Architecture Design Gate Premature microservice fragmentation; unrecorded non-functional trade-offs lacking an ADR.

Zero AI Garbage & Vibe Code Standard

Universal WebDev Skills enforces strict bans on synthetic AI bloat, placeholder comments, and generic vibe-code templates.

🚫
Explicitly Banned AI Trope Patterns:
  • Placeholder Comments: Code comments like TODO: implement or FIXME are strictly forbidden. Implementation must be complete and tested.
  • AI Vibe-Design Templates: Gratuitous rainbow/purple gradients, fake decorative macOS terminal window chrome, and hollow glowing cards.
  • Folder Sprawl: Arbitrary scratchpads, unrequested markdown files, or directories nested deeper than 3 levels.

Multi-Tool Adapters

Automated adapters wire the 15-specialist protocol directly into any developer environment.

In addition to root configuration files, modern Cursor (v0.40+) utilizes modular .cursor/rules/*.mdc rules scoped via glob patterns:

.cursor/rules/06-security.mdc 
---
description: HARD VETO: OWASP Top 10, parameterized SQL, scrypt hashing, and secret protection
globs: **/*.{env*,auth*,login*,crypto*,security*,ts,js,py,go}
alwaysApply: false
---

HARD VETO active: Never concatenate raw SQL strings (mandate driver parameterization).
Never hardcode secrets. Passwords must use scrypt/argon2 with unique salts.
Validate all inputs against strict schemas.
