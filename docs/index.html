The 3-Tier Rigor Standard

Never over-engineer a 2-user prototype; never under-engineer a revenue-critical production release.

MVP TIER

Proof of Concept

Triggered by prototypes, single-user apps, and internal hackathon tools where velocity is the top priority.

  • Speed & single-file simplicity prioritized
  • Scrypt password hashing with unique salts
  • Parameterized SQL (0 string concatenation)
  • Baseline defensive CSP & nosniff headers
  • Strict scope cut (Must-Haves only)
PROD TIER

Production & Commerce

Triggered by public users, customer auth, payment/checkout, or sensitive personal data.

  • Strict Idempotency-Key handling & caching
  • ACID atomic inventory deduction (no negative stock)
  • Container liveness & readiness health probes
  • Zero-downtime expand-and-contract migrations
  • HSTS, strict CSP, and server-authoritative pricing
SCALE TIER

High-Traffic Distributed

Triggered by >100k MAU, spiky traffic patterns, or strict high-availability SLAs.

  • Edge caching (s-maxage, stale-while-revalidate)
  • ETag conditional GET (304 Not Modified)
  • Zero Cumulative Layout Shift (CLS = 0)
  • Cookieless privacy-preserving analytics
  • Automated rollback scripts with telemetry
